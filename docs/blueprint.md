# **App Name**: Who Owes Us?

## Core Features:

- Politician Search & Filtering: Allow users to find politicians by offices held, year of service, or case status through a comprehensive search and filtering interface on the homepage.
- Accountability Leaderboard: Display a ranked list of politicians based on their dynamically calculated accountability score, with sorting options.
- Politician Profile View: A detailed profile page for each politician, showcasing full name, offices held, party history, a timeline of associated cases (with sources), and satirical badges.
- Comparison Tool: Enable users to compare corruption-related records, conviction counts, forfeiture amounts, and accountability scores for 2-3 selected politicians side-by-side.
- Content Sharing System: Generate optimized, auto-populated social cards and 'Did you know?' snippets for easy sharing on popular social media platforms.
- Admin Data Management Panel: A secure administrative interface for manual data entry, update, source attribution, and moderation of politician and case records.
- Satirical Badge Generator: Leverage a generative AI tool to dynamically create context-relevant, non-defamatory satirical badges ('Frequent Court Visitor', 'Asset Recovery Contributor') for politician profiles based on their specific case histories and scores.

## Style Guidelines:

- The visual design emphasizes transparency and civic duty. The primary brand color is a deep, trustworthy blue (#0C3D99). The background color is a very light, almost white grey-blue (#EBF1F3) derived from the primary hue, providing a clean canvas. An accent color in a moderate purple tone (#895CDD) is used for calls to action and important highlights, creating contrast and conveying resilience.
- The main font for all text, including headlines and body, will be 'Inter' (sans-serif), chosen for its modern, neutral, and highly readable qualities, ideal for a data-first and civic-tech aesthetic.
- Utilize clean, crisp icons that convey their meaning directly. For general UI elements (search, filters, share), standard and easily recognizable symbols are preferred. Satirical badges will feature custom, thematic icons that subtly hint at the badge's meaning without being aggressive.
- The layout prioritizes a data-first approach with clear organization and readability. Content will be structured using a responsive grid system, especially for leaderboards and data tables, to ensure optimal display on various screen sizes. Politician profiles will feature well-defined sections for easy digestion of information, including a chronological timeline view for cases.
- Subtle and functional animations will be incorporated to enhance user experience without distraction. These will include smooth transitions for data filtering, sorting changes on the leaderboard, and loading states for content. Micro-interactions will provide immediate feedback to user actions.
